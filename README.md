## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_prank_about`** outlines the safe comedy principles, executive leadership, and bilingual web platform behind the prank entertainment division of **UNIVERSE HUOKAING THARA Group**. Visitors can filter division pillars, search topics live, and inspect domain notes inside a modal dialog.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔎 Live Search & Pillar Filtering:** Filter pillars (*Safety & Ethics, Leadership, Platform & Tech*) or search rules, roles, and technical details in real time.
* **🛡️ Division Brief Modal:** Inspect each pillar's domain and oversight summary inside a modal dialog.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.
